# image-to-mouse-drawing-bot
Convert images into mouse-drawn sketches automatically using Python and OpenCV 

## About this project
This is an initial version of a bot I built with help from AI, especially for the OpenCV parts.

You might ask: why does this exist if there are already many tools out there?

1. I had a lot of free time, haha, and I wanted to build something.
2. The main reason: Revolut lets you order a custom card where you can place a hand-drawn sketch. Drawing something detailed with just your finger is hard, especially when you want clean lines and better detail.

So this was my solution: I share my phone screen and use this script to automate the drawing process more precisely.

I plan to add a graphical interface and maybe include more improvements over time.

Hope this is useful for you.
